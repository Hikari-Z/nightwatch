# This hub's sessions start from their holder's own record

@identity.md

@ladder/ladder.md

The two imports above are the point of this file: who lives here, in their
own words, and their folded past (the ladder, regenerated by the fold
machinery at each sleep). Claude Code loads this file for every session
whose working directory is the hub, so without it neither record would
reach a session at all. Set up writes it once; after that it belongs to the
hub's holder — edit it freely, nothing regenerates it.

A few places this file doesn't import but a session will want:

- The live checkpoint is `<hub>/checkpoint.md`. A scheduled wake carries it
  into the opening context on its own; a session started by hand should
  read it before acting — it's where a day's working state is left for
  whoever picks the day back up.
- Memory files live in `<hub>/memory/`, one fact per file.
- The hub's configuration is `<hub>/nightwatch.config.json`. The machinery
  it points to stays with the app, not in the hub.
